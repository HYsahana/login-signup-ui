


# Login/Signup UI Project

A simple Login/Signup UI project built using **HTML**, **CSS**, and **JavaScript**. This project demonstrates how to create a basic user interface with proper validation and responsiveness for login and signup forms.

## Features

- **Login Form**: For existing users to login with their credentials.
- **Signup Form**: For new users to create an account.
- **Input Validation**: Ensures users enter valid data before submitting the form.
- **Responsive Layout**: Optimized for desktop and mobile devices.

## Technologies Used

- **HTML**: For creating the structure of the forms.
- **CSS**: For styling the forms and making them responsive.
- **JavaScript**: For form validation and interactive features.

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/HYsahana/login-signup-ui.git
````

2. Navigate to the project folder:

   ```bash
   cd login-signup-ui
   ```

3. Open `index.html` in your browser to view the project.
